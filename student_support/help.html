Make the failure
reproducible.

Share four things: exact command, exact error with secrets removed, provider, and model.

First: isolate the layer

Run the offline lab check. If that passes and inference fails, inspect provider setup. Keep transport failures separate from security decisions.

.venv/bin/python tools/student_replay.py --lab lab1 --runtime "$REPLAY_ENV"
Missing API key

Save the named provider key in the course-root .env; Python loads it automatically. Exported values take precedence. Never paste a key into a command, report, or screenshot.

401 / 403

Check the chosen provider, account permissions, and credential. Repeat preflight using a new receipt filename after correcting access.

429 / quota

Stop the batch. Check the provider quota or wait for its documented reset. Record missing cases; do not count a rate limit as a blocked attack.

503 / outage

Keep the error evidence. Retry later or select another provider/model explicitly, with a separate preflight and result file.

Invalid JSON / schema mismatch

Preserve the raw response and validate the expected fields. A prose baseline may intentionally fail JSON. Do not silently rewrite the reply into a passing answer.

OUTPUT_TRUNCATED

The completion budget ran out. The shared adapter retries once with a bounded larger allowance. If it still truncates, keep that execution failure separate from JSON quality, refusals, and security decisions.

Tool unavailable

The Agent uses the course JSON action protocol. Inspect the action name and arguments: only calc and search_corpus are allowed. Native function calling is optional.

Scanner missing

Use .venv/bin/python -m pip install -r requirements.txt and .venv/bin/python -m pip check. Add the local .venv/bin to PATH as shown in Runtime Setup. Scanner findings on the intentionally vulnerable lab are expected.

Promptfoo mismatch

Use Node 22.22.0 and the locked Promptfoo 0.123.1 environment from the runtime page. Use COURSE_PYTHON for the installed course interpreter.

Reset a replay

Only remove the generated reports/offline/<lab> directory for the lab you intend to replay. Keep results you need for comparison. Do not remove source files or your environment.
