Prepare once

From the extracted course root, create Python 3.12 locally and install the small preflight profile:

python3.12 -m venv .venv
.venv/bin/python -m pip install -r runtime/requirements-preflight.lock

Save LLM_PROVIDER=openrouter, MODEL_ID=deepseek/deepseek-v4.1-flash, and your own OPENROUTER_API_KEY in the course-root .env. The Python tools load this file automatically. Exported values take precedence; no shell sourcing is needed.

The small profile has 3 direct dependencies, 12 packages with pinned versions. Before the complete labs, extend the same environment with .venv/bin/python -m pip install -r requirements.txt. See the complete runtime guide for pinned Node and Promptfoo.

Never put a key in a command, screenshot, shared file, or submission. The optional --prompt-key flag accepts a hidden key for a one-time check.

Core ready means API, exact model, strict JSON, and the harmless synthetic security case all pass. Labs 1–2 can start then.

Full ready also passes the optional long-context and tool checks. Safe Agent needs Full Ready or a compatible provider switch. This is a setup check, not full application certification.

provider_setup_receipt.json stays on this machine and contains no key, hidden reasoning, or private account ID; token counts and returned cost are safe metadata. For a later Full Ready check, use --full --receipt provider_setup_receipt_full.json to keep the core receipt unchanged.
