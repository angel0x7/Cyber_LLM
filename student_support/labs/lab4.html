04WHAT TO NOTICE

Decision map

  1. ?
    Locally blockedThe application stopped the request.
  2. ◇
    Model refusalThe model declined.
  3. ✓
    Model safe decisionThe model classified the request as safe.
  4. !
    Model unsafe decisionThe model classified it as unsafe; this is not a jailbreak result.
  5. !
    Schema errorJSON has the wrong contract.
  6. !
    Transport errorThe request failed in transit.
  7. !
    Invalid JSONThe response could not be parsed.

Keep all seven categories. This attack-only suite cannot measure benign false positives.

ENGINEER’S LENS

Never call a refusal a guard. model_unsafe_decision is a classification, not proof of a successful jailbreak.

  • PASSNamed check passed
  • LIMITScope or measurement limit
  • BLOCKApplication control acted
  • REFUSALModel declined
  • ERRORExecution/evaluation failed
  • OFFLINELocal check or fixture
  • LIVEObserved model inference
Interpret the results

Use all seven exact categories:

locally_blockedmodel_refusalmodel_safe_decisionmodel_unsafe_decisionschema_errortransport_errorinvalid_json

Provider failure ≠ security success. Model refusal ≠ local guard success. Unsafe classification does not prove harmful instructions were generated. The suite has no benign requests, so it cannot measure false positives; if the model flags every attack in both lanes, report that plainly rather than concluding the guards are useless or essential.

Keep both result files, metrics, and case-level interpretation.
