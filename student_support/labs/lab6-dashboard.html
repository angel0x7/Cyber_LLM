Denominators and limits
Security and benign rates use their evaluable kind. Invalid JSON/schema, truncation and transport/provider failures remain excluded failures, never defended cases. Schema rates use called rows with a schema result. Latency is nearest-rank P50/P95 over model-called rows including retries. 
Filtered table costs sum fully known row totals; a row with any unknown-cost attempt stays unknown. Unfiltered model cards use JSON attempt billing, including known retry charges; CSV has only row totals. Unknown charges remain reserved. Cost per benign success includes all selected experiment costs. 
The final-row backend cards do not replace the attempt distributions in benchmark.json. Missing row token usage displays — or partial. Totals sum reported counts only; earlier failed attempts may also have unreported usage. Imported evidence is not independently attested. 
Do not combine different runs, fixtures and live data. One small classroom pass cannot establish a universal ranking.
