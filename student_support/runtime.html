LLM Security / Install once. Replay in order.

One runtime for the whole course

Install once.
Replay in order.

Tested baseline: Linux x86_64, Python 3.12, Node 22.22.0, Promptfoo 0.123.1. On Windows use WSL2 with Ubuntu. Installation needs package registries; offline replay does not.

1 / Python

Open a terminal at the extracted course root, beside requirements.txt. Use the course-local Python 3.12 environment for every command.

python3.12 -m venv .venv
.venv/bin/python -m pip install -r runtime/requirements-preflight.lock
.venv/bin/python tools/provider_preflight.py --provider openrouter --model deepseek/deepseek-v4.1-flash
# Before starting the complete labs, extend the same environment:
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m pip check
export REPLAY_ENV="$PWD/.venv"
export COURSE_PYTHON="$REPLAY_ENV/bin/python"

Save your provider configuration in the course-root .env : LLM_PROVIDER=openrouter , MODEL_ID=deepseek/deepseek-v4.1-flash , and your local OPENROUTER_API_KEY . Python loads it automatically; exported values take precedence. Keep this file private.

OpenRouter DeepSeek is a paid route, course-replayed by the instructor with measured limitations; run your own CORE READY check before lab work.

The preflight profile has 3 direct dependencies and 12 locked packages. The full profile adds the scanners, notebooks, and retrieval runtime. Optional helper: python3.12 tools/bootstrap_runtime.py --preflight, then --full or --doctor.

2 / Node and Promptfoo

Download the official Node 22.22.0 Linux x64 archive and verify its SHA-256 against the official checksum file, then extract it into your runtime.

curl --fail --location https://nodejs.org/dist/v22.22.0/node-v22.22.0-linux-x64.tar.xz -o "$REPLAY_ENV/node-v22.22.0-linux-x64.tar.xz"
curl --fail --location https://nodejs.org/dist/v22.22.0/SHASUMS256.txt -o "$REPLAY_ENV/SHASUMS256.txt"
(cd "$REPLAY_ENV" && grep '  node-v22.22.0-linux-x64.tar.xz$' SHASUMS256.txt | sha256sum -c -)
# Continue only if the checksum says OK.
tar -xJf "$REPLAY_ENV/node-v22.22.0-linux-x64.tar.xz" -C "$REPLAY_ENV"
mkdir -p "$REPLAY_ENV/node-tools"
cp runtime/package*.json "$REPLAY_ENV/node-tools/"
export PATH="$REPLAY_ENV/node-v22.22.0-linux-x64/bin:$REPLAY_ENV/bin:$PATH"
npm ci --prefix "$REPLAY_ENV/node-tools"
export COURSE_PYTHON="$REPLAY_ENV/bin/python"
export PROMPTFOO_CLI="$REPLAY_ENV/node-tools/node_modules/promptfoo/dist/src/main.js"
node --version
"$COURSE_PYTHON" tools/bootstrap_runtime.py --doctor
node "$PROMPTFOO_CLI" --version

Expected versions: v22.22.0 and 0.123.1. This is the pinned teaching baseline; no global Promptfoo install is needed.
