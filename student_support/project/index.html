SHARED REQUIREMENTS

Evidence is part of the application.

Both tracks use input and output guards, a validated JSON contract, application replay logs, Promptfoo evaluation through the actual application adapter, and offline CI checks. The local corpus and starter code are in project application entrypoint.

Run the common offline application replay before choosing your change:

COMMAND
.venv/bin/python tools/student_replay.py --lab project --runtime "$REPLAY_ENV"

It writes reports/offline/project/results.json, metrics.csv, coverage details, and results.application.jsonl. Model responses are fixtures; application code and local tools are real.
