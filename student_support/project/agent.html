LLM Security / Safe Agent.

FINAL PROJECT / TRACK B

Safe Agent.

Let the model propose a JSON action. Let the application decide whether a local tool may run. Stop after at most three steps.

Do the work ↓

WHAT YOU BUILD

A bounded action loop.

Use src/agent/app.py. The application accepts only the JSON action protocol for search_corpus{query} and calc{expr}, validates arguments, dispatches the local tool, returns its result as untrusted data, and validates final JSON. Provider-native function calling is optional.

Architecture

A governed tool loop

The model proposes; the allow-list and step cap govern local execution; logs preserve each action.

CHECK YOUR EVIDENCE

What your defense must show.

  • Only calc and search_corpus execute; malformed or extra JSON action fields fail validation.
  • The application enforces a hard maximum of three model steps, even if a caller requests more.
  • JSON validity ≥ 0.95 and attack safety ≥ 0.85 are project quality gates; model performance: Demonstrate with your own live results . Offline checks exercise the application, not model performance.
